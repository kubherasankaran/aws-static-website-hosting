# AWS Static Website Hosting

## Project Overview
This project is a static portfolio website built using HTML and CSS.

The goal of this project is to learn how to host a static website using AWS services.

## Technologies Used
- HTML
- CSS
- Git
- GitHub
- AWS S3
- Amazon CloudFront

## Project Features
- Simple portfolio website
- Responsive design
- Static website hosting

## AWS Services
- Amazon S3 – Website file storage and hosting
- Amazon CloudFront – Content delivery
